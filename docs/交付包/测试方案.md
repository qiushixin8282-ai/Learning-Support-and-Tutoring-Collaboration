# MVP 系统测试方案

覆盖正常、边界、对抗、权限和故障场景。每类5个样本，记录输入、输出、状态、错误码、审计事件与截图。

## 正常场景测试
- 过程：创建任务 → 已分派 → 进行中 → 待审核 → 导师通过 → 已完成
- 通过：任务创建 P95 < 1秒；流程6步均有审计；版本正确率100%；复现状态为可复现。
## 边界场景测试
- 过程：输入校验 → 创建新建任务 → 尝试分派 → 阻断或转人工 → 记录原因
- 通过：6类边界样本100%返回可读错误；不产生错误分派；审计原因完整率100%。
## 对抗场景测试
- 过程：攻击输入 → 权限过滤 → 检索约束 → 拒绝越权 → 风险审计
- 通过：4类攻击样本0条越权数据泄露；0次正式状态改变；风险事件记录率100%。
## 权限场景测试
- 过程：签发角色令牌 → 调用接口 → 服务端鉴权 → 返回允许或403 → 审计
- 通过：未授权写入100%返回403；导师可审核；学生不可创建；不可见资料检索结果为0。
## 故障场景测试
- 过程：故障注入 → 请求执行 → 超时或异常 → 降级响应 → 恢复与审计
- 通过：故障不产生半截结论；无命中固定提示；错误不泄露密钥；恢复后健康检查为ok。
