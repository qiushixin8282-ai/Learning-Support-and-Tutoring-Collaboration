# 六人访谈记录

> 教学演练样例（虚构），用于需求调研方法演示，不代表真实客户访谈。

## IV-01 学习服务主任
- 核心陈述：需要把继续试点的决定、停止条件和价值口径写清。
- 量化线索：每周复盘一次，缺少统一时长和返工指标。
## IV-02 助教
- 核心陈述：资料散在群文件、共享盘和代码仓库，版本核对靠人工。
- 量化线索：每周约3次查找资料，每次约25分钟。
## IV-03 课程运营员
- 核心陈述：交接时常缺规则版本和具名责任人，需反复补问。
- 量化线索：每周约2次，每次约20分钟。
## IV-04 课程讲师
- 核心陈述：专业结论和特殊学习支持必须由讲师最终判断。
- 量化线索：审核意见应包含依据、修改项和验收条件。
## IV-05 教育数据专员
- 核心陈述：资料可见范围、脱敏、留存与审计尚待具名确认。
- 量化线索：未授权资料不可进入学生检索范围。
## IV-06 平台工程师
- 核心陈述：现有系统需提供状态变化、责任人、版本与异常日志。
- 量化线索：先做单课程受控试点，再验证接口与回滚。
